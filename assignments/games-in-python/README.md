
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. You will learn string manipulation, conditionals, loops, and random selection.

## 📝 Tasks

### 🛠️ Hangman Game Implementation

#### Description
Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (underscore format: _ _ _)
- Track incorrect guesses remaining
- End when word is guessed or attempts exhausted
- Display win/lose messages
